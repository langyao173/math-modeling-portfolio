# 世界杯数据挖掘与概率预测系统：技术报告

## 摘要

本项目在完整保留 A 题三项指定基线的前提下，构建了一个时间因果正确、跨任务概率一致、可审计且可一键复现的世界杯预测系统。生产链路只依赖 Python；MATLAB R2026a 仅用于候选模型筛选与跨语言数值核验。所有正式模型只使用赛题给出的 1930–2014 数据；2014 严格排除在模型选择、超参数搜索与校准之外，冻结审计完成后才允许纳入情景接口的部署态重拟合。2018 总进球 169 只用于问题 1 的一次性外部审计，任何 2026 输出均为“截止 2014 的情景演示”，不是现实赛程预测。

最终系统同时交付：题面指定 OLS/多项逻辑回归、静态历史联合进球分布、研究级动态强度候选、半场第二阶段增量模型、严格时序验证、经验区间、概率与对称性不变量、拟合状态哈希、预测证书以及完整 manifest。

| WorldCupPlayers.csv | 37,784 | 37,048 | `753a68af0cd4fa38b67c7883c138700dfb37544f1ed898b1d176a03f92748d67` |

比赛表按 `(RoundID, MatchID)` 去除 16 条完全重复记录，未发现冲突重复组；球员表去除 736 条完全重复事件。规范化后的 2014 世界杯为 64 场、171 球、已知观众总数 3,386,810。唯一缺失的规范化比赛观众数保留为缺失值，并由训练期统计量在模型内部处理，不利用测试集反推。所有 20 届赛事的场数、总进球和观众数均与赛事汇总表完成程序化对账。

历史阶段被统一为 `group_stage`、`round_of_16`、`quarter_final`、`semi_final`、`final` 和 `third_place` 六类。点球大战只影响晋级，不覆盖全场统计比分；因此平局仍为 `draw`，避免标签语义混杂。

## 2. 问题 1：总体统计、趋势与 2018 审计

严格使用题面公式：

\[
\text{GoalsScored}=\beta_0+\beta_1\text{QualifiedTeams}
+\beta_2\text{MatchesPlayed}+\beta_3\text{Attendance}+\varepsilon.
\]

`Year` 不进入该回归。由于题面没有给出 2018 总观众数，系统先用 1930–2014 的“每场观众数”拟合预先冻结的对数线性时间外推，再乘以 64 场，得到 3,828,410 的情景输入；没有调用真实 2018 观众数。

20 届样本上的拟合结果为：

- \(R^2=0.7919\)，调整 \(R^2=0.7529\)；
- LOOCV MAE = 14.8107，RMSE = 18.8497；
- 三个非截距项的 HC3 p 值分别为 0.4025、0.1664、0.5691，均未达到 0.05；
- VIF 为 10.18、18.44、7.82，说明赛事规模变量之间存在明显共线性，不能把单个系数解释为稳定因果效应。

冻结模型预测 2018 总进球 152.553，真实审计值为 169，带符号误差为 -16.447；基于 LOOCV 绝对残差的经验 90% 区间为 [116.080, 189.026]。这说明模型抓住了规模趋势，但 20 个赛事级样本不足以支持精细系数解释或高置信度外推。

## 3. 问题 2：单场总进球与半场更新

### 3.1 描述统计

| 统一阶段 | 场数 | 总进球 | 场均进球 |
|---|---:|---:|---:|
| 小组赛 | 622 | 1,691 | 2.719 |
| 16 强 | 81 | 251 | 3.099 |
| 四分之一决赛 | 62 | 175 | 2.823 |
| 半决赛 | 34 | 123 | 3.618 |
| 决赛 | 19 | 68 | 3.579 |
| 三四名决赛 | 18 | 71 | 3.944 |

半场总进球与全场总进球 Pearson 相关系数为 0.6957（836 场），说明半场信息具有较强预测力，但不能决定最终结果。

### 3.2 题面 OLS

题面模型只使用统一阶段、半场总进球和观众数。训练集为 1930–2010 的 772 场，2014 的 64 场只测试一次。2014 指标为 MAE 0.9744、MSE 1.3661、RMSE 1.1688、\(R^2=0.5542\)。可复用的 2026 小组赛情景输入（半场 1 球、观众 45,000）给出全场总进球点预测 2.5341。

### 3.3 非负第二阶段增量模型

增强模型直接建模非负的下半场增量：

\[
G^{FT}=G^{HT}+G^{2H},\qquad G^{2H}\ge 0.
\]

经验区间只使用 1986–2010 的严格扩展起点 OOF 残差，共 412 个残差；跨时序校准诊断覆盖 360 场，目标覆盖率 0.90，经验覆盖率 0.9306。按部署时同样执行“区间下界不低于已观测半场进球”的逐场截断后，平均区间宽度为 3.7643。相同演示输入的增强预测为 2.6146，经验 90% 区间为 [1.0000, 4.5337]。该区间不满足 IID 交换性假设，因此只报告经验覆盖，不声称无条件 conformal 保证。

## 4. 问题 3：赛前胜平负与联合进球分布

题面多项逻辑回归严格使用四个赛前差值：历史参赛次数、历史最佳名次、历史场均进球和历史场均失球。每个特征只聚合当前世界杯之前已经完成的赛事，并通过镜像样本与预测对称平均保证换队对称性。

2014 冻结测试上，题面逻辑回归 accuracy 为 0.5313、macro-F1 为 0.3887、log loss 为 0.9926、multiclass Brier 为 0.5919。平局召回率为 0，这是必须明确保留的失败模式：accuracy 不能代表三类概率质量，也不能掩盖少数类失效。

最终增强模型使用相同四个可获得历史特征构造静态联合进球分布，并采用 Dixon–Coles 低比分相关修正。2014 审计上 accuracy 同为 0.5313，但 log loss 降至 0.9889、Brier 降至 0.5890；改善幅度很小，不能表述为决定性胜出。

BRA–GER 仅作为截止 2014 的接口演示，不代表真实 2026 对阵。静态联合模型输出：主胜 0.4805、平 0.2635、客胜 0.2560；期望进球 1.4904–1.0144；最高概率比分 1–1；条件总进球 90% 区间为 [0, 5]。证书中的 OOD 分数为 2.1949，显式计入历史特征距离以及 48 队、104 场的赛制漂移。

## 5. 研究层与选型边界

动态研究候选增加预测前 Elo、进攻状态和防守状态，并在一个联合比分核中同时派生主胜、平局、客胜、比分和总进球。它是严格因果的逐场赛前估计：同届较早比赛结束后才更新状态，因此不是完全赛前的整届静态预测。候选选择仅使用 1986、1990、1994、1998、2002、2006、2010 七个扩展起点外层折；2014 在全部选择冻结后才打开。

与题面逻辑回归相比，动态 Joint Poisson 在七折中的平均 log loss 差为 -0.01577，Brier 差为 -0.01111，均有 6/7 折改善；单侧 Wilcoxon 精确 p 值分别为 0.1094 和 0.0781。方向一致但样本折数太少，不能声称传统显著性。2014 审计中，动态候选 accuracy 为 0.5781、log loss 为 0.9597；开发期拟合的校准集成 log loss 为 0.9548。校准器是在汇总开发 OOF 预测上拟合并诊断的，因此其开发期指标不被伪装成额外 held-out 证据。

动态候选通过了预注册工程门槛，但没有进入 2026 生产情景：赛题未提供可在 2026 预测时刻获得的动态球队状态。最终部署静态历史 Joint Poisson；动态版本明确保留为研究候选。这一区分避免把“历史验证较好”错误等同于“现实 2026 输入可用”。

## 6. 概率一致性、不确定性与证书

所有联合比分矩阵均为非负且归一化，主胜/平/客胜概率由同一矩阵派生；换队后主客概率交换，半场模型满足全场总进球不低于已观测半场总进球。每个正式预测 JSON 包含：信息集、数据截止、原始数据哈希、特征 schema/hash、真实拟合状态文件/hash、配置 hash、随机种子、软件版本、校准方法、区间、OOD 分解、结构不变量和限制性警告。

预测 JSON 排除生成时间，因此相同输入下字节稳定；完整证书保留生成时间。独立验证器同时核对 manifest 的文件清单/大小/SHA-256、证书 schema、模型文件存在性以及 `model_hash` 与实际模型文件字节是否一致。

## 7. MATLAB R2026a 的边界与结果

MATLAB R2026a Update 3 只用于候选筛选和 Python 数值核验。赛事级 LOOCV 中，OLS MAE/RMSE 为 14.8107/18.8497，ridge 为 13.8637/17.4780，Poisson 为 14.8725/19.2186。MATLAB 与 Python 在原始/规范化行数、2014 汇总、六阶段统计、四项描述统计和半场/全场相关系数上的最大绝对误差不超过 \(10^{-10}\)。候选结论只在 Python 中重新实现后才可进入正式链路；MATLAB 截图或 `.mat` 文件不作为最终证据。

## 8. 主要创新

1. **信息集分离**：赛前、开赛时和半场特征分别登记可用时间，并自动检查 `available_time <= prediction_time`。
2. **跨任务联合概率核**：比分、胜平负和总进球来自同一联合分布，消除三个任务相互矛盾的问题。
3. **半场增量建模**：预测非负第二阶段增量，而不是无约束回归全场总进球。
4. **赛制与时代漂移显式化**：动态研究模型处理历史迁移，生产证书同时报告 2026 赛制 OOD 分解。
5. **模型级可审计预测**：预测不仅给答案，还给数据、schema、配置、真实拟合状态、校准和不变量证据链。

## 9. 局限与结论边界

- 数据只到 2014，不能回答真实 2026 阵容、状态、赛程或伤停问题。
- 只有 20 届世界杯，赛事级推断与显著性检验功效有限。
- 2014 是单届外部测试；它不能单独决定模型优劣。
- 题面逻辑回归和平滑联合模型均未解决平局召回为 0 的问题。
- 经验区间和条件比分分布不包含完整参数不确定性，也不提供无条件覆盖保证。
- 世界杯历史中的国家实体继承、赛制和竞争强度并非完全平稳。

因此，本项目的核心结论不是“已准确预测 2026”，而是已经建立了一套在给定数据边界内合规、时间正确、概率一致、可复现且能诚实表达不确定性的预测系统。
