## 打开工作台

直接打开 `product/风险复核工作台.html`，可浏览2,907名客户、筛选名单、查看账务图表、调用证据工具，并在本机保存办理记录。六页依次为客群总览、风险队列、客户分析、证据办理、AI协同、任务接续。

跨浏览器接续同一案件时，在本目录运行：

```bash
python product/agent_server.py
```

访问 `http://127.0.0.1:8765`。动作表单登记发起方、资质变化、原始凭证及证据可用月份。相邻月2,677人构成完整评分批次，268个名额按最终评分排序；“边界保护”入口可查看两名需要放宽的客户。

默认Agent执行账务检索、计算、解释与材料检查。机构语言模型可按操作说明接入，原始数值与工作流状态由工具服务计算。机构接入还需映射统一身份、岗位权限与工单回执。

## 重新生成报告

安装 `requirements.txt` 中的Python依赖和XeLaTeX，在本目录执行：

```bash
python code/manuscript_tables.py
python code/v18_framework.py
python code/v18_figures.py
python code/revision_figures.py
python code/build_paper_v18.py
python code/verify_current_manuscript.py
```

编译直接使用保存的全部图件。表格与新图来自 `evidence/current/`；重算客户配对区间可先运行 `python code/integrate_capacity_results.py`。早期的独立面板、参考周期和外部终点图件保留各自固定来源，分别解释其数据与终点。

修改产品页面后，运行 `python code/render_workbench.py` 重新生成单文件网页。在 `product/` 安装 `package.json` 中的jsdom后，运行 `node export_workbench_dom.cjs`，再在根目录运行 `python code/print_paper_workbench.py`，可重新生成正文六页面集成图。六个页面由实际网页DOM运行后导出，按两列三行集成；示例办理记录通过本机领取与保存流程产生。

## 评分复算

```bash
python code/verify_batch.py
```

该脚本重放8,491个状态、5,584次更新，检查预定名单保持、批次完整性、并列处理和重复提交。底模、校准、原始历史特征构造器及示例位于 `scoring/`。`ProtectedBatchScorer.advance_batch` 接收完整候选批次、前次状态、固定名额及预期快照键，输出基础预测、近稳候选、最终评分和逐户原因。成员或容量改变后整批重算。

主评分保护10%容量的底模入选成员；六容量版本同时保护5%、8%、10%、12%、15%、20%边界。容量保护不冻结完整排序，风险指标、概率损失与尾部变化均以最终评分单独计算。

## 作业试验

```bash
python product/trial/server.py --port 8768
```

访问 `http://127.0.0.1:8768`。试验有18个正式案例和3个练习案例，每人办理9案、每界面3案，同人不重复同案。材料可提交、盲评、退回并继续办理；失败与返工计入总工时。答案文件由试验主持人保管，网页服务不公开答案。

试验固定案例与界面版本。24名从业者为计划先导规模，真人工时、正确率与收益由现场记录回收。主工作台展示最新容量保护评分；作业试验保留其固定案例读数，用于评价界面和证据接续。

## 结果口径

主标签为评分后三个月已观察DPD>0，未知结局保留为空且占用名额。提额月、相邻月共有99、88个事件窗口；跨期独立事件客户按客户去重。研究使用既有历史队列和冻结模型，42项尾部同时区间描述客户抽样变异。严重风险随访与外部核销分别列示。

网页载荷仅保留评分时可见的账务及评分，不含未来结局。经营性提额依据机构审批与策略凭证确认；参考使用率和真实超限分别判断。完整原始数据获取与最初训练过程由原研究包保留，本包集中提供本稿编辑、图表复算、评分推断和产品运行材料。

附录三视图与作业网页共用界面代码。修改后先运行 `python code/build_trial_offline.py` 更新离线练习。在 `product/` 安装jsdom后，运行 `node trial/export_views.cjs`，再在根目录执行 `python code/print_trial_figure.py` 重建图A7。离线练习页 `product/043_复核作业_可交互练习.html` 提供同一版本的三个独立练习案件。
