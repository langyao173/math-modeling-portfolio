# 风险复核工作台

## 打开与保存

直接在浏览器打开 `风险复核工作台.html`，可使用账务图表、工具助手和本机案件办理。需要多浏览器接续同一案件时，在工作包根目录运行：

```bash
python product/agent_server.py
```

访问 `http://127.0.0.1:8765`。Windows可使用 `启动工作台.bat`；macOS/Linux可使用 `start_workbench.sh`。案件服务仅依赖Python标准库。服务连接后，办理材料保存在 `product/runtime/cases.sqlite3`；可通过 `FINTECH_CASE_DB` 指定路径，`FINTECH_AGENT_PORT` 指定端口。

## 一次复核的办理过程

1. 选择名单范围。名单复核268户，差异核对6户，持续观察2,592户，逾期核对40户，账务补齐1户，共2,907户。
2. 从待领取、我经办的、到期跟进等视图进入。可按线索或编号筛选、点击散点定位客户，保存常用视图；每批最多分派30案。
3. 在近六期账务图中查看余额、额度、还款和最低应还，点击月份读取原始明细。提额发生期与最新相邻月可以切换。
4. 使用率三视图比较上期实际、本期旧尺度和本期实际。统一评分q用于排序；Q=100(1−q)为其反向百分制显示。更新分解同时展示基础信息变化与约束修正。
5. 调用AI复核助手生成简报、使用率说明、评分说明或材料检查。点击[S1]至[S6]定位工具依据，核实后将草稿填入办理记录。
6. 在“证据与办理”登记账户、账务、额度动作、参考周期四项核对结果和凭证。待补材料设置责任岗与跟进日期，保存后接续。
7. 材料齐备后提交另一位操作员复审，可批准或退回。完成案件出现新材料时，记录原因重新办理，原有意见和事件连续保留。

机构接入时，经办身份和岗位权限由统一身份系统提供，动作凭证、工单回执和对客办理接入现有业务系统。公开历史客户用于展示和核验页面操作。

## 数据口径

工作台含2,907名客户及17,441条可见月度余额记录，缺失月保留空值。相对月份以客户申请时点为原点，金额沿用Home Credit原始单位。2,866名客户有评分，其中2,677人组成最新相邻月完整批次，按最终q排序并固定268个名额；其余189人保留原有快照，进入持续观察或差异核对；40名已逾期客户直接进入逾期核对，1名缺失账务客户接续补件。

基础评分融合参考尺度244维XGBoost与414维LightGBM，独立校准后执行条件约束更新。账户、模型和参考周期保持一致、两期均未逾期且七字段近稳时，允许更新区间为前次q上下1个百分点；其余满足评分条件的记录完整更新。随后执行容量保护，使10%复核名单与基础预测名单一致。若1个百分点边界与入选条件冲突，只作必要放宽；页面展示放宽幅度和批次依据。最终评分、指数及变化使用同一输出。

## 案件版本与备份

每次保存形成递增版本。服务端以事务检查版本和请求编号；并发冲突时，可保留本页草稿再加载最新记录。材料提交后，复审基于该版本进行。

单文件页面可导出案件JSON备份；服务模式提供一致性数据库备份：

```bash
python product/manage_workspace.py status
python product/manage_workspace.py backup --output backups/cases.sqlite3
```

恢复时先停止服务，将备份路径传入 `FINTECH_CASE_DB` 后启动。浏览器工作空间与服务工作空间分别保存。

## Agent与机构语言模型

默认工具模式在本地执行检索、计算和材料检查。语言模型增强通过以下服务端配置接入：

- `FINTECH_LLM_BASE_URL`：兼容服务根地址，包含 `/v1`。
- `FINTECH_LLM_MODEL`：机构选定的模型标识。
- `FINTECH_LLM_API_KEY`：服务凭据。

在工作空间设置中检查连接并选择增强模式。模型接收当前案件证据包，组织带引用的文字草稿；数值计算及办理状态由确定性工具和工作流处理。凭据保存在服务端。


## 页面与示例案件

顶部“展示视图”提供适合演示的页面密度；“完整视图”恢复全部办理控件。六个主页面共享当前客户与案件状态，页签切换会保留已保存的材料。

- 客群总览：点选作业分流或风险评分区间，进入对应名单。
- 风险队列：筛选、领取与分派客户。
- 客户分析：查看账务轨迹、使用率与评分更新。
- 证据办理：登记依据、跟进计划，并保存或提交复审。
- AI协同：运行工具，点击S1—S6查看来源，将草稿填入当前案件。
- 任务接续：查看岗位进度、到期跟进与版本时间线。

“边界保护”筛选展示本期两个必要放宽案件。在“证据办理”登记动作发起方、核心资质变化、原始凭证和证据可用观察月；保留参考周期必须有银行经营动作且资质未变的原始依据。原因未知时可转交补件。打印视图由实际运行后的页面内容导出。
