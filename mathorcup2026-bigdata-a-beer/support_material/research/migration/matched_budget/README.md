# 同预算、同QP低类别余量强对照

本补试检验原研究中的改进是否仅来自更多字段修改或更深的目标距离下降。所有候选使用同一目标 `H=P+0.2I`、相同L1重加权路径、支持抛光、proxy负余量修复网格和完整名义验收。新增策略仅把类别logit余量置为原来的 `1e-5`，以旧32个开发场景在预算60和100内选择；其余旧对照的候选完全固定，未重新优化。

`protocol.json` 与 `PROTOCOL_LOCK.json` 先于候选搜索；`CANDIDATES_FROZEN.json` 和63个独特冻结候选先于新验证。验证seed为 `202610251503`，100次风格分层重采样，不复用已经查看过的v1新200场景。每次重拟合分类器以及完整六族、50目标感官模型，沿用原固定权重。

## 完整关键结果

| 预算 | 策略 | 可用来源 | 全11来源联合频率 | 平均编辑数 | 实际距离下降 |
|---|---|---:|---:|---:|---:|
|60|原最少编辑|11/11|16.09%|22.27|10.67%|
|60|同QP低余量|11/11|22.18%|47.18|30.05%|
|60|余量1旧候选|11/11|56.64%|38.18|20.79%|
|60|余量2旧候选|10/11|77.00%|40.80|19.68%|
|100|原最少编辑|11/11|16.09%|22.27|10.67%|
|100|同QP低余量|11/11|33.64%|77.27|46.51%|
|100|余量2旧候选|11/11|90.09%|76.73|41.47%|

预算60下，余量1相对同QP低余量提高34.45个百分点，配对场景块95% Monte Carlo区间为[30.91,38.00]个百分点。预算100下，余量2提高56.45个百分点，区间[52.45,60.36]个百分点；11个来源的差值均为正。

低余量策略在两项比较中都使用了更多编辑，实际目标距离下降也更深，却有更低的重拟合联合频率。因此结果排除了“仅增加编辑预算或更接近目标中心已足以解释全部收益”的解释，支持类别余量约束在该固定建模流程中的作用。它不证明其他问题、任意求解算法或真实酿造干预的一般优越性。

必须同时保留新旧验证块：余量1在v1新200场景中为65.73%，本新100中回落到56.64%；余量2预算100分别为90.86%和90.09%。不能隐藏前者的跨块波动，也不能把200与100重复堆叠成独立啤酒样本。

## 论文用表与原始证据

- `matched_summary.csv`：全部7个策略—预算组合，完整覆盖、成本、实际距离、分类/感官/联合频率。
- `matched_paired_comparisons.csv`：8项预定对照的同场景配对差及场景块区间。
- `matched_per_source.csv`：每一来源的100场景成功次数、CP下界，含缺失来源。
- `validation_draws.npz`：全部类别余量、50维候选减源预测、六族陈旧味分量、新索引及候选ID。
- `frozen_frontier.csv`、`frozen_profiles.csv`、`CANDIDATES_FROZEN.json`：冻结候选与预算映射。
- `analysis.json`：审计结果与统计解释；`FINAL_READBACK.json`记录所有数值文件的原子回读。

全部区间只衡量相同250款观测数据和既定重拟合规则下的条件Monte Carlo不确定性；场景块保留11来源相关性。这不是独立新啤酒的泛化区间或真实配制成功率。

## 复现

设置 `MATHORCUP_PROJECT_DIR` 为恢复的原项目根目录，包含官方数据和冻结六模型、控制模型及分类器。依赖与上一级 `requirements.txt` 一致。运行：

```bash
python replay_frozen.py --output /absolute/path/replay_new100 --workers 2
```

该入口只重放本次已经冻结的100场景，不重新选择候选。`run_matched.py` 保存新低余量候选构造、旧32开发选择与新验证的原始工作流。独立审计结果由上级工作包保留。
