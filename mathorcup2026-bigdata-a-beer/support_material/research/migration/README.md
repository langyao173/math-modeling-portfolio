# 类别余量与有限场景迁移实验

本实验比较原最少编辑方案、固定logit余量1、固定logit余量2与32个开发重拟合分类器的共同半空间方案。严格化学缺陷约束、目标距离至少下降10%、固定完整六模型陈旧味非增以及训练支持盒保持相同；候选按实际修改的225个直接字段计成本。

## 已完成结果

- 32个旧重拟合场景只用于开发和候选选择。
- 冻结98个独特候选后，使用新seed `202610250731` 生成200个风格分层重采样场景，重拟合六类完整50目标模型及分类器。
- 主展示预算60在验证运行中、尚未读取验证结果时锁定，具体记录见 `all11/PRIMARY_ANALYSIS_LOCK.json`。它是盲态补充的展示决定，不追溯声称为最初预注册。
- 原最少编辑的全11来源平均联合频率为20.45%。预算60下余量1覆盖11/11、联合65.73%，平均38.18次编辑；余量2覆盖10/11、全11计分78.82%；有限场景法同覆盖下79.09%，相对余量2的增量区间跨零。
- 预算100下余量2覆盖11/11、联合90.86%，平均76.73次编辑；有限场景法90.55%、平均67.36次编辑。它降低编辑数，但没有显示更高的联合频率。
- 稳定性由更多字段修改换得，不能表述为同成本优越。90.86%是来源均值，逐源结果最低72%，不能写成各源均达到90%。
- 只允许61个标定浓度字段时，增强余量后的名义可行覆盖更低。这一追加诊断未进入已经冻结的200场景验证，仅作为补充输出，不作更好可实施性的结论。

## 关键输出

- `all11/validated_frontier_summary.csv`：四种方法、六个预设预算、全11来源及已覆盖来源均值。
- `all11/publication_paired_comparisons.csv`：同一模型场景内的配对比较与场景块区间。
- `all11/publication_per_source.csv`：预算60和100的逐源成功次数及Clopper–Pearson下界。
- `all11/validation_draws.npz`：200场景的类别余量、完整50维预测差、六族陈旧味预测差、索引和候选标识。
- `all11/frozen_validation_profiles.csv`、`development_frontier.csv`及冻结记录：未经验证结果选择的候选及映射。
- `all11/all_candidate_checks.csv`：包括未通过完整验收的方案，不以失败来源或条件子集替换全部来源。

置信区间仅衡量固定250款观测数据及既定重拟合规则下的Monte Carlo不确定性。场景块抽样保留11个来源之间的相关性；不能把200×11视为2200个独立样本，不能把该频率称为真实配制成功率或独立新啤酒的泛化性能。

## 复现入口

需要原项目中的官方 `data/A/1.csv` 与 `4.csv`、冻结六模型、控制模型、分类器及本实验保存的冻结候选。设置 `MATHORCUP_PROJECT_DIR` 指向该项目目录。依赖见 `requirements.txt`。

已冻结候选的完整验证可用 `replay_frozen.py`，它不再选择候选，只按原seed重拟合和重放。`run_scenario.py` 与 `repair_candidates.py` 保存候选生成及修复实现；独立去重审计与6个恢复候选位于 `audit_pipeline/`。每个验证缓存绑定查询、模型规格、权重及场景索引指纹，防止不同候选误用旧缓存。

## 追加的同预算强基准

为排除“更多编辑或更深目标距离本身造成收益”的解释，另做了新seed100场景补试，见 [`matched_budget/README.md`](matched_budget/README.md)。它新增同一QP和相同支持构造的低余量策略，旧margin1/2与原最少编辑的候选保持固定：预算60下低余量22.18%、余量1为56.64%；预算100下低余量33.64%、余量2为90.09%。两项比较中低余量使用更多编辑、距离改善更深，却有更低稳定性。全部正负对照、来源覆盖及配对场景块区间均保留。该补试不重写v1新200场景的结果。

补试的精确冻结重放入口为 `matched_budget/replay_frozen.py`，依赖沿用本目录的 `requirements.txt`；不需重新优化或选择候选。
